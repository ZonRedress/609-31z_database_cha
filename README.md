# 609-31z_database

## 📋 Описание
Это реляционная база данных для **информационной системы бронирования консультаций с психологами**. Система предназначена для хранения информации о пользователях (клиенты и психологи), их профилях, доступности и консультациях. Реализована с использованием MySQL и может быть развернута через phpMyAdmin или любую другую СУБД с поддержкой MySQL.

## Структура базы данных

### 1. `users`
Хранит общую информацию о всех пользователях системы:
- `first_name`, `last_name`
- `email`, `phone`
- `role` — клиент или психолог

### 2. `psychologists`
Дополнительная информация о психологах:
- Специализация
- Опыт работы
- Биография

### 3. `clients`
Дополнительные данные о клиентах:
- Дата рождения

### 4. `availability`
График доступности психологов:
- Дата, время, статус (свободен/занят)

### 5. `appointments`
Консультации между клиентами и психологами:
- Дата, тема, статус, заметки
